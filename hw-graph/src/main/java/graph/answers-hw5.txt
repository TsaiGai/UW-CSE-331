CLASS - Graph
    I decided to only include one class for the interface because it would be simpler to
    have all the methods in one class. When issues arise, debugging multiple classes wouldn't
    be necessary.

METHODS - createGraph, addNode, addEdge, listNodes, listChildren
    createGraph - this method constructs the empty graph for nodes to be added to. It's
    necessary as a framework for the nodes and edges.
    addNode - this method creates and adds a node to the graph. It's necessary for adding
    new nodes.
    addEdge - this method creates and adds an edge to the graph, connecting two nodes.
    It's necessary for adding new edges.
    listNodes - this method lists the nodes in the graph. It's necessary for visualizing
    the nodes in the graph.
    listChildren - this method lists the children of a respective parent node. It's necessary
    for visualizing a parent node and its children.
